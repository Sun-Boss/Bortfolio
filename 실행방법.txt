이 프로젝트(Next.js/React)를 다른 컴퓨터나 IDE에서 실행하려면 다음 단계가 필요합니다.

1. 필수 프로그램 설치 확인
- 컴퓨터에 Node.js (https://nodejs.org/) 가 설치되어 있어야 합니다. (안 깔려있으면 설치 필수!)

2. 패키지(node_modules) 설치
- 소스코드를 열고 있는 IDE(VS Code 등)에서 '터미널(Terminal)'을 엽니다.
- 아래 명령어를 입력하고 엔터(Enter)를 누릅니다.
  npm install

3. 프로젝트 실행
- 설치가 완료되면(에러 없이 끝나면), 아래 명령어를 입력하고 엔터를 누릅니다.
  npm run dev

4. 웹페이지 확인
- 터미널에 'Ready in ...' 또는 'Local: http://localhost:3000' 이라는 문구가 뜨면 성공입니다.
- 인터넷 브라우저(크롬, 엣지 등)를 열고 주소창에 아래 폴더 주소를 입력하세요!
  http://localhost:3000

* 주의: 위 창을 닫거나 터미널을 끄면 서버가 종료되어 홈페이지 접속이 불가능합니다.
